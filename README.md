# SLS Magic AutoSnap Bangunan

**Auto Snap Wilkerstat 2026** — QGIS plugin for manual point correction, KML Map Marker matching, Join Titik review, georeferencing tools, audit and data-quality workflows.

## Latest prepared package

- Version: **2.17.82**
- Package: `SLS_Magic_AutoSnap_Bangunan_v2.17.82_BLUE_SNAP.zip`
- Highlights: blue snap reticle with a larger orange center; updater endpoint configured for this repository.

## Installation

1. Download the ZIP asset from the latest GitHub Release.
2. In QGIS, use **Plugins → Manage and Install Plugins → Install from ZIP**, or replace the existing plugin folder after fully closing QGIS.
3. Back up GPKG/GeoJSON source data before applying coordinate edits.
4. Review Map Marker and Join Titik candidates before executing changes.

## Updates

The plugin checks this repository's **GitHub Releases** endpoint for the latest release and looks for a ZIP asset. To make updates available to users, publish a release and attach the installable plugin ZIP as an asset. A source commit alone does not publish an installable plugin package.

## Data quality notice

This plugin is an assistance tool and can perform aggressive correction workflows. Always review previews, changed coordinates, attributes and audit reports before using outputs as final data.
